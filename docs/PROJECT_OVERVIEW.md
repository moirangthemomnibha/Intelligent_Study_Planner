# Project overview

## Goal
Generate personalized study schedules and adapt them to a student's progress, workload, deadlines and priorities.

## Core workflow
1. Student profile and availability
2. Subjects, topics, exam dates and topic metadata
3. Priority calculation
4. Single-day and multi-day schedule generation
5. Session completion/missed-session tracking
6. Adaptive rescheduling
7. Analytics and AI recommendations
8. Agentic study manager for monitoring, proposing and carrying out approved planning actions

## Agentic AI boundary
The agent can analyze, recommend, simulate and prepare schedule changes. Keep a human approval step for major changes (for example, deleting sessions, changing exam dates or overriding the student's availability). Record the reason for each proposed action.
