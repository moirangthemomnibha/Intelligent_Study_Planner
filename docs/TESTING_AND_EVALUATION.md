# Testing and evaluation

Measure more than whether the app creates a timetable.

Suggested metrics:
- Schedule coverage: required topics scheduled before their deadlines.
- Session completion rate: completed / planned sessions.
- Recovery quality: how well the plan recovers after missed sessions.
- Deadline risk: number of high-risk topics detected early.
- Prediction error: predicted vs actual time needed per topic.
- Recommendation usefulness: student rating and acceptance rate.
- Agent safety: invalid actions blocked and high-impact actions confirmed.

Compare a fixed timetable with the adaptive planner using the same workload and available study hours.
