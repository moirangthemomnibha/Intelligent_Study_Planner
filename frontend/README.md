# Frontend

React + Vite application.

- `src/pages/`: full screens such as Dashboard, Subjects and Planner.
- `src/components/`: reusable UI widgets.
- `src/api/client.js`: backend HTTP requests.
- `src/context/`: shared authentication and planner state.
- `src/styles/`: global styling.

Run `npm install` and `npm run dev`. Connect each page to the matching backend API as the weekly milestones are completed.
